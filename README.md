# 龙回头策略完整方案（一年数据版）

> 本文档记录基于 **232 交易日（2025-09-22 ~ 2026-09-15）**、**1179 条**结构合格样本（**817 只**股票）重新寻优得到的龙回头策略完整设计。
> 目标：让任何读过本文档的人（含开发者自己）都能独立复现、理解、落地这套策略。
> 数据来源：涨停池（hithink）→ 日线（hithink）→ 分时（eltdx，240 点/日）。

> **本版相对旧版（80 天版）的关键变更**：旧版的核心结论（"详细版优于简版"、"S1 尾盘 14:45 是主力路"、**S2 路**的"加分项分层加码"、"8% 止盈"）在一年数据上被证伪，已全部删除并替换。详见 [第 1 节](#1-方法论与约束) 与 [第 12 节](#12-置信度与风险提示)。

---

## 0. 核心结论（速览）

1. **买点只有两个：D+1 开盘、D+2 开盘**。D 日尾盘 14:45 买点为负期望，**整路废弃**（三段全负：-1.13% / -0.63% / -0.57%）。
2. **早盘/盘中买点全部不成立**：用"截至买点可知"的形态判定后，早盘买点均为负收益；旧版看到的正收益是未来函数假象。
3. **两路并行**：`S2 = D+1 开盘（高位跳水型）`、`S4 = D+2 开盘（缩量反转型）`，旧版 S1（尾盘排雷）、S3（次日高弹性）已删除。
4. **卖出规则两路一致：无止盈 + 3% 止损 + 持 1 个可卖日**。旧版的「8% 止盈」是负贡献（把两路压到 +0.86% / +1.43%），但该对比行实为「8% 止盈 + **4%** 止损」，与推荐规则「无止盈 + **3%** 止损」同时改变了止损档，故**不能单独归因于止盈**——止损档本身也影响结果（3% 止损 vs 4% 止损两路差约 +0.35pp / +0.22pp）。5% 止盈直接转负。
5. **止损是主要保护来源**：去掉止损后两路单笔期望从 +2.51% / +2.83% 掉到 +1.31% / +1.87%。
6. **加分项加码只在 S4 路成立**（0分 +0.98% → 1分 +1.90% → 2分 +3.10% → 3~6分 +5.79%，**全量口径**单调）；**S2 路非单调**（0分 +1.23% > 1分 +0.66%），只宜作观察标记。注意：S4 分层仅在**全量口径**单调，**A/B/C 分段并不单调**（B 段 3~6 分档降至 +0.51%；0 分档 C 段为 **-2.18%**），且 3~6 分档 n=20 样本偏小，故加码证据强度中等。
7. **组合模拟（推荐版：两路各 20% 仓 + S4 按分加码、总上限 80%）**：
   - A 段 +64.85%（日均 +0.984%）/ B 段 +76.97%（+1.156%）/ **C 段样本外 +65.23%（+1.064%）** / 全量 +382.71%（+1.075%）
   - 最大回撤 -7.79%（C 段 -5.89%）
8. 触发频率：组合去重后 **311 次（≈1.34 次/日）**；两路各自命中 180 / 165 次（重叠 34 次，按优先级只计一次）。

## 1. 方法论与约束

### 1.1 无未来函数原则（最重要）
- 14:45 买入 → 量比必须用"**截至 14:45 的累计量**"，不能用全天量。
- 早盘买入 → 形态判定**不能**用 `收盘位置 / 全天最低时刻` 等全天数据；只能用截至买点可知的 `low/hi/current/回升幅度`。
- 实测反例：用全天标签的"收敛形态@09:45" 显示 +0.43%，换成"截至买点可知"的判定后只有 -1.41%（该 `-1.41%` 来自更早的 **dr2 阶段分析**，非本轮一年数据的可复现输出，此处仅作定性说明）—— **早盘买点优势是未来函数造成的假象**。

### 1.2 T+1 规则
- D 日买入 → 第一个可卖日 = D+1。
- D+1 开盘买入 → 第一个可卖日 = D+2。
- D+2 开盘买入 → 第一个可卖日 = D+3。
- 本文所有"持 1 个可卖日"指：买入后到下一个交易日收盘了结（除非触发止损）。

### 1.3 分时索引映射（已实测确认）
- 240 点。09:31~11:30 = 索引 0~119；13:01~15:00 = 索引 120~239。
- **09:35=4 / 09:40=9 / 09:45=14 / 10:00=29 / 10:30=59 / 11:00=89 / 11:30=119 / 13:30=149 / 14:00=179 / 14:30=209 / 14:45=224**。
- 截至 14:45 累计量 = `cumv[225]`（含索引 224 当点）。

### 1.4 量纲
- hithink 日线 volume = **股**；eltdx 分时 volume = **手**，换算 ×100（`MINUTE_VOL_TO_SHARES=100`）。
- 分时 `time_label` 为零填充 `"HH:MM"`，可直接字符串比较。

### 1.5 三段互不重叠切分（本版方法论核心修正）

旧版把样本按 2/3 切成"训练/测试"，同时又有"新增段/旧窗口段"，两套切分几乎重合，导致"三段同向"退化为"两段同向"，☆ 标记失去意义。本版改为**互不重叠的三段**：

| 段 | 区间 | n | 用途 |
|---|---|---|---|
| **A 最老** | D < 2026-01-13 | 383 | 选因子 |
| **B 中段** | 2026-01-13 ~ 2026-05-29 | 432 | 选因子 |
| **C 最新** | D ≥ 2026-05-29 | 364 | **真·样本外验证**（= 旧版 80 天研究窗口） |

**铁律：选因子只用 A+B；C 段只用于验证，绝不参与选择。** 任何因子/组合必须 A、B、C 三段全部为正才可采纳；禁止只报全量结果。

### 1.6 稳健贪心
- 目标 = **最大化 min(A 段期望, B 段期望)**，硬约束 = 两段期望**同时 > 0**。
- 覆盖度下限 `min_n = 45`（宽口径，推荐）；同时用 `min_n = 22`（窄口径）作过拟合对照。

### 1.7 因子池覆盖说明
本轮因子池**完整覆盖**旧版详细版用到的全部因子，并按「买点时刻信息是否已知」重新分池：
- 14:45 路只用截至 14:45 已知的量价（把旧版的 `d_low_pct` / `vol_vs_wavemean` 换成 `low45` / `v45_wm` 同期口径），消除未来函数；
- D+1 路可用 D 日全天字段；D+2 路再加 T 日全天字段。

每组 12~16 类、共 **40+ 个档位**，覆盖连板数、三类量比、量能趋势、开盘/最低/振幅、一字板、分时形态、收盘位置、低点时段、次日开盘/量比/收盘、再下日开盘。

## 2. 个股/样本筛选（前置条件，全部满足才算"龙回头形态"）

1. 至少 **2 连板**（紧邻无间隔），且连板是**临近波**。
2. 连板波后紧邻一根**首阴**（收盘 < 开盘），且首阴是最后一根 K 线（截至判定日）。
3. 排除三板组 `is_sanbanzu`。
4. 只针对 **60/00 主板非 ST** 股票；排除创业板、科创板、北交所、可转债。
5. 疑似融券股/单字连板等风险项通过现有 `analyzer` 的 `suspect` 标识排除。

## 3. 两路策略总览

| 路 | 类型 | 买点时间 | 触发条件（硬门槛） | 卖出规则 | n | 全量期望 | A / B / C |
|---|---|---|---|---|---|---|---|
| **S2 高位跳水型** | 稳健 | **D+1 开盘** | 分时形态=尾盘跳水 + 首阴振幅≥8% + 次日开盘≤-3% | 无止盈 + 3%止损 / 持1日 | 180 | **+2.51%** | +3.00 / +2.57 / **+1.89** |
| **S4 缩量反转型** | 弹性 | **D+2 开盘** | 次日量/首阴量<0.6（缩量） + 首阴振幅≥8% | 无止盈 + 3%止损 / 持1日 | 165 | **+2.83%** | +2.06 / +2.78 / **+3.64** |

**已删除的路**：
- ~~S1 尾盘 14:45 · 排雷型~~：A+B 双段约束下**无任何因子组合能成立**，三段全负，整路废弃。
- ~~S3 次日开盘 · 高弹性（连板≥2 + 量能趋势[0.7,1.05]）~~：该组合是旧版 80 天窗口的产物，一年数据下不成立，并入 S2。

**两路对照单路**（C 段样本外，均为**基础版**：每路固定 20% 仓、不加码）：两路并行 +51.90% > S4 单路 +44.57% > S2 单路 +22.13%，故采用两路并行。注意此处 +51.90% 指**基础版**，与 §0/§7 推荐的**推荐版**（S4 按分加码，C 段 +65.23%）不同，勿混淆。

## 4. S2 次日开盘 · 高位跳水型

### 4.1 硬门槛（3 条，全部必须 AND）
1. **首阴分时形态 = 尾盘跳水**（`shape_label == "尾盘跳水"`）
2. **首阴振幅 ≥ 8%**（`d_amp_pct >= 0.08`，小数口径，0.08 = 8%；即首阴当日最高/最低振幅）
3. **D+1 开盘涨幅 ≤ -3%**（`t.open_pct <= -0.03`，低开确认恐慌）

> 注：门槛只用 D 日全天字段 + D+1 开盘价，均在 D+1 开盘前可知，无未来函数。

### 4.2 加分项（**不可加码**，仅作观察标记）
硬门槛之外，A/B/C 三段都为正的加分候选：
`首阴开盘 0~+3%` | `首阴量/前日量 [1.0,1.5)` | `连板≥3` | `连板≥4` | `首阴最低 >-2%（浅）` | `一字板=0`

实测分层**非单调**（0分 +1.23% > 1分 +0.66%，2分才回到 +2.76%）→ **只宜在提示卡片上标注，不可据此线性加仓**。

### 4.3 实测
- 硬门槛 + 3% 止损 + 持1日：n=180，**+2.51%**（A +3.00 / B +2.57 / C +1.89）
- 硬门槛 + 4% 止损（未调优前）：n=180，+2.16%（A +2.82 / B +2.18 / C +1.43）

### 4.4 卖出
- **无止盈**；**-3% 止损**；D+1 开盘买入 → 持到 D+2 收盘了结（触发止损则提前离场）。
- 旧版的"8% 止盈 / 低开砍仓"已删除（均为负贡献）。

## 5. S4 再下日开盘 · 缩量反转型

### 5.1 硬门槛（2 条，全部必须 AND）
1. **次日量/首阴量 < 0.6**（`t_vol_vs_d < 0.6`，D+1 相对首阴**缩量**）
2. **首阴振幅 ≥ 8%**（`d_amp_pct >= 0.08`）

> 注：门槛只用 D 日全天字段 + T 日（D+1）全天量，均在 D+2 开盘前可知。

### 5.2 加分项（**可加码**，全量口径单调）
硬门槛之外，A/B/C 三段都为正的加分候选（6 条）：
| # | 加分项 | 字段 |
|---|---|---|
| ① | **次日（D+1）开盘 0~+3%** | `t.open_pct in [0, 0.03)` |
| ② | 首阴形态 = 尾盘跳水 | `shape_label == "尾盘跳水"` |
| ③ | 首阴形态 = 冲高回落 | `shape_label == "冲高回落"` |
| ④ | 首阴低点时段 ≥ 90 分 | `mp_D.low_time_i >= 90` |
| ⑤ | 次日收盘 ≥ 0% | `t.close_pct >= 0` |
| ⑥ | 首阴低点时段 30~90 分 | `mp_D.low_time_i in [30, 90)` |

> 注：加分 ①实为 **次日（D+1）开盘**（候选串标记 `topen`，对应 `t.open_pct`），并非再下日开盘。

### 5.3 实测分层（全量口径单调，可加码）
| 分数 | 全量 | A | B | C |
|---|---|---|---|---|
| 0 分 | n=31 **+0.98%** | -0.29% | +3.94% | -2.18% |
| 1 分 | n=58 **+1.90%** | +1.84% | +1.76% | +2.13% |
| 2 分 | n=56 **+3.10%** | +2.28% | +3.07% | +3.74% |
| 3~6 分 | n=20 **+5.79%** | +5.19% | +0.51% | +10.79% |

→ **全量口径**下分数越高期望越高，适合按分数加码；但 **A/B/C 分段并不严格单调**（B 段 3~6 分档降至 +0.51%；0 分档 C 段为 **-2.18%**），且 3~6 分档 n=20 样本偏小，加码证据强度为**中等**。

### 5.4 实测
- 硬门槛 + 3% 止损 + 持1日：n=165，**+2.83%**（A +2.06 / B +2.78 / C +3.64）

### 5.5 卖出
- **无止盈**；**-3% 止损**；D+2 开盘买入 → 持到 D+3 收盘了结。

## 6. 卖出规则（两路统一）

| 规则 | 结论 |
|---|---|
| **止盈** | **不设**。旧版「8% 止盈 + 4% 止损」把两路压到 +0.86% / +1.43%，但该行同时改变了止损档（推荐为 3% 止损），**不能单独归因于止盈**（止损档本身也影响结果：3% 止损 vs 4% 止损两路差约 +0.35pp / +0.22pp）；5% 止盈直接转负（-0.62% / -0.12%） |
| **止损** | **-3%**（分钟级触发）。去掉止损后两路降到 +1.31% / +1.87% |
| **持有期** | **持 1 个可卖日**。持 2 日 min(A,B) 与持 1 日几乎相同，但样本外 C 段持 1 日更好（+1.89% vs +1.53%），且资金占用翻倍 |
| **低开砍仓** | **不设**（旧版结论：低开≤-3% 就卖是负贡献） |

规则选择目标与选因子一致：**max min(A,B)，并列（相对差 < 5%）时优先持 1 日**。

## 7. 仓位配比与合并规则

### 7.1 基础仓位与动态加码
| 路 | 基础仓位 | 是否按加分项加码 | 单路上限 |
|---|---|---|---|
| **S2 高位跳水** | **20%** | ❌ 不加码（分层非单调） | 20% |
| **S4 缩量反转** | **20%** | ✅ 加码 | 30% |

加码公式（仅 S4）：`单笔仓位 = min(20% × (1 + 0.25 × 加分项数), 30%)`

### 7.2 总仓位控制
- **同一日历日总仓位 ≤ 80%**（组合风控）。
- 若当日累加超过 80%，**等比例压缩**。
- 说明：等比压缩后当日总仓位恰为 80%，**不存在"压缩后仍超过"的情形**，故无需"降级为仅观察"的兜底规则。

### 7.3 多路去重（按样本）
优先级 **S2 > S4**（D+1 路优先于 D+2 路）。**同一样本（同一票同一 D 日）内**多路命中时，只取最高优先级一路提示，**不叠加仓位**。
> 注意：S2 买于 D+1 开盘、S4 买于 D+2 开盘，本属**不同日历日**；去重实际按**样本**（同一票同一 D 日）判定，而非按日历日。

### 7.4 组合模拟结果

| 配置 | 段 | 累计 | 日均 | 日胜率 | 回撤 | 均占用 |
|---|---|---|---|---|---|---|
| **推荐版**（两路20% + S4加码） | A | +64.85% | +0.984% | 51% | -7.79% | 40.9% |
| | B | +76.97% | +1.156% | 59% | -3.85% | 47.0% |
| | **C（样本外）** | **+65.23%** | **+1.064%** | 51% | -5.89% | 41.5% |
| | 全量 | +382.71% | +1.075% | 54% | -7.79% | 43.4% |
| 基础版（两路20%，不加码） | C（样本外） | +51.90% | +0.882% | 49% | -5.46% | 37.6% |
| 对照·窄口径（n≥22） | C（样本外） | +8.40% | +0.418% | 40% | -5.94% | 26.0% |

→ 推荐版三段全部优于基础版，样本外 C 段提升最明显，回撤仅多 0.28pp。窄口径严重过拟合，宽口径明显更优。

## 14. 实现口径说明

本节汇总开发落地时必须明确的口径，消除正文中的歧义。

### 14.1 止损撮合口径
以可卖日分钟序列逐点判定，当某点 `收益 ≤ -3%` 时按 **-3% 成交**（回测无跳空/滑点假设）。实盘需按实际成交价，滑点会使真实结果更差。

### 14.2 止损生效日（关键）
止损**仅在可卖日生效**：
- S2 在 D+1 开盘买入、可卖日为 D+2，故 **D+1 全天无止损保护**；
- S4 在 D+2 开盘买入、可卖日为 D+3，故 **D+2 全天无保护**。

这是与"随时可砍"直觉不符的关键点，务必注意。

### 14.3 卖出兜底
持 1 个可卖日，按可卖日**收盘价**了结；若当日一字跌停无法卖出，回测按收盘价成交（乐观假设），实盘会延续到下一可卖日，需人工处理。

### 14.4 加分项入选标准
硬门槛之外，要求 A/B/C 三段期望**都为正**且每段 **n≥30**，按三段较差期望排序取前 6 条。S2 与 S4 各 6 条。

### 14.5 加码档位示例
公式 `min(基础仓 × (1 + 0.25 × 加分项数), 基础仓 × 1.5)`。基础仓 20% 时：0 分→20%、1 分→25%、2 分→30%（触顶）。

### 14.6 加分项互斥说明
S4 的 ④`mp_D.low_time_i ≥ 90` 与 ⑥`30~90` 互斥，同一样本不可能同时满足；故 6 条加分项实际最多满足 5 条。

### 14.7 三段切分阈值是快照
A/B/C 的切点（2026-01-13、2026-05-29）取自当时样本的中位数位置，数据窗口变化后会漂移，复现时需按同口径重新计算。

### 14.8 S2 不可加码的原因
S2 分层非单调（0 分 +1.23% > 1 分 +0.66%），若强行加码会引入负贡献。
